# Список покупок — React

Небольшое учебное приложение на React: можно добавлять товары с ценой, удалять их и видеть общую стоимость.

## Что используется
- React и `useState` для хранения товаров и значений полей.
- `props` для передачи товара и функции удаления в компонент `ShoppingItem`.
- `map()` для отображения списка.
- `filter()` для удаления товара.
- `reduce()` для подсчёта общей стоимости.
- Vite для запуска и сборки проекта.

## Запуск на компьютере

1. Установи Node.js, если он ещё не установлен.
2. Открой папку проекта в VS Code.
3. В терминале выполни:

   ```bash
   npm install
   npm run dev
   ```

4. Открой адрес, который покажет терминал (обычно `http://localhost:5173`).

## Сборка для публикации

```bash
npm run build
```

Готовые файлы для публикации появятся в папке `dist`.

## Публикация на GitHub Pages

Для простого способа публикации через GitHub Actions можно использовать workflow, который собирает Vite-проект и публикует папку `dist`. Перед публикацией проверь настройки GitHub Pages в репозитории.

Примечание: список не сохраняется после перезагрузки страницы — для этого в проект пока не добавлена база данных или `localStorage`.
